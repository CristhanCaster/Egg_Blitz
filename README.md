# Egg Blitz

A Flask + Neon PostgreSQL multiplayer creature hatching game.

## Local setup

1. Install Python 3.11+.
2. `pip install -r requirements.txt`
3. Set `DATABASE_URL` to your Neon **pooled** PostgreSQL connection string and `SECRET_KEY` to a long random secret. Without DATABASE_URL, local SQLite is used.
4. `python app.py`
5. Open http://localhost:5000

## Render deployment

1. Push the contents of this folder to a **private** GitHub repository (keep `app.py`, `requirements.txt`, `render.yaml`, `templates/`, `static/` at the repository root).
2. In Neon create a project, then copy the pooled connection string. Neon connections typically use `postgresql://...`.
3. In Render create a Blueprint from the GitHub repository using `render.yaml`, or create a Python Web Service with build command `pip install -r requirements.txt` and start command `gunicorn app:app --bind 0.0.0.0:$PORT`.
4. Set Render environment variable `DATABASE_URL` to the Neon connection string; `SECRET_KEY` is generated by the Blueprint, or set it manually to a long random value for a manual service. **Never commit these secrets to GitHub.**
5. Deploy and visit the Render URL. The database tables initialize automatically.

## Gameplay

- New users get 250 coins; click for +10 (server limited to 1 click per 0.18 seconds).
- Basic, Cyber, Galaxy eggs with independent rarity probabilities.
- Strongest 3 pets automatically form the squad; leaderboard ranks by total squad power.
- Fuse three duplicate Common or Rare pets into a random creature one tier higher.
- Daily coin streak bonus every 24 hours.
- Speed math rewards 90 coins for an answer within 3 seconds (signed expiring challenge token).
- Redeem code `WELCOME` once per account for 1,000 coins.

## Creating promo codes

The `Code` table holds admin-created codes. Use a trusted database console to insert records, e.g.:

```sql
INSERT INTO code (code,reward,value,max_uses,uses)
VALUES ('BLITZSECRET','creature','Blitz Zero',100,0);
```

Valid rewards: `coins` (integer value), `creature` (exact species name), `tag` (text up to 20 characters). Set `max_uses` to 0 for unlimited global redemptions. Each account can redeem a given code once.

## Production notes

This is a playable starter release, not a fully hardened high-scale economy. For a major public launch add account recovery, bot protection, IP rate limiting, CSRF protection, database migrations, observability, and transaction locking for simultaneous economy actions. Do not run multiple workers for serious competitive play until atomic database updates are added. No real-money payments are included.

## Custom pixel art
All 17 creatures have individual original 32x32 pixel sprite designs (scaled crisply to 192px), located in `static/sprites/`. They display in the Dex, inventory, active squad, and hatch reveal. Undiscovered creatures show silhouettes.

## Expanded creature collection

This edition includes **317 creatures** (the original 17 plus 300 new creatures). Every added creature has its own 40×40 transparent pixel-art PNG. Designs combine 20 distinct body silhouettes with 15 independently drawn physical motifs, facial variations, and palettes; they are not simple recolors. All new creatures are included in hatching, fusion, the Dex, inventory, and leaderboard power calculations. Existing saved creatures are compatible.
